# 1Fi SDE1 Assignment

A full-stack EMI marketplace application built using React,
Tailwind CSS, Node.js, Express, Prisma and PostgreSQL.

## Features

- Dynamic product data
- PostgreSQL database
- REST API
- Product variants
- EMI plans
- Cashback
- Interest rates
- EMI plan selection
- Responsive UI
- Unique product URLs

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

### Backend

- Node.js
- Express
- Prisma

### Database

- PostgreSQL
